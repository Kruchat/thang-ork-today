# ทางออกวันนี้

เว็บ **ปัญหาเดียวต่อวัน → ทางออกเดียว**  
ทำฟรีก่อน ของช่วยได้ไม่เกิน 1 ชิ้น บางวันไม่มีของขาย

## เปิดใช้

เปิดผ่าน GitHub Pages (หลังเปิดใน Settings → Pages → Deploy from branch `main` / root)

หรือรันท้องถิ่น:

```bash
python3 -m http.server 8080
```

## หน้า

| หน้า | หน้าที่ |
|------|--------|
| `/` | ฉบับวันนี้ |
| `/archive.html` | ย้อนหลัง |
| `/admin.html` | ร่าง / นำเข้า AI / วางลิงก์ Shopee / เผยแพร่ |

รหัสหลังบ้านเริ่มต้น: `1234`

## เชื่อม AI

1. หลังบ้าน → ใส่ AQI / อากาศ
2. กด **คัดลอกพรอมป์**
3. วางใน ChatGPT / Claude / Grok
4. วาง JSON กลับ → **นำเข้าจาก AI**
5. วางลิงก์นายหน้า Shopee → **เผยแพร่**
